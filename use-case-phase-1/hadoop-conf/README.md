# Hadoop client configuration for CAI Workbench HDFS CLI

Place your **cluster-specific** client configs here (download from Cloudera Manager / CDP):

- `core-site.xml` (required)
- `hdfs-site.xml` (required)
- `ssl-client.xml` (recommended for TLS clusters)
- `log4j.properties` (optional)

`krb5.conf` is generated by the notebook **Environment Settings** cell from `KRB_REALM` /
`KRB_DOMAIN`, so users on different systems can change realm without hand-editing this file.

Set identity via the notebook (or env vars):

```bash
export KRB_USER='your_user'
export KRB_REALM='YOUR.REALM.EXAMPLE'
# optional overrides:
# export KRB_PRINCIPAL='your_user@YOUR.REALM.EXAMPLE'
# export KRB_DOMAIN='your.realm.example'
# export HADOOP_CONF_DIR=/path/to/hadoop-conf
# export KRB_KEYTAB=/path/to/your.keytab
```

Replace the XML files when pointing at a different CDP environment.
